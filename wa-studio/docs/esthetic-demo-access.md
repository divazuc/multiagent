- בכניסה ראשונה מדפדפן חדש יופיע מסך **"דאשבורד דמו — גישה למפעיל בלבד"** — מזינים את **מפתח המנהל** (ADMIN_API_KEY).

- אחרי כניסה אחת הדפדפן זוכר את המפתח — במחשב שכבר נכנסת ממנו לא יופיע מסך כניסה.

**מה יש בפנים:** 4 זונים (מרכז 🏠 / הכשרות וקורסים 🩺 / טיפולים אסתטיים 💉 / השתלות שיער 💇 — הסטריפ העליון מחליף צבע לפי הזון), סקירה עסקית עם ROI, מרכז לידים, שאלות ותשובות עם "שאלות מהשטח", והגדרות עם זהות פר-בוט ומדיניות בצ'קבוקסים.

> 💡 **מסך לבן?** ריענון קשיח — `Ctrl+Shift+R` (קורה רק אם טאב ישן נשאר פתוח מזמן פריסה).
